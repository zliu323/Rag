# 数据治理规范（人工编写的虚构评测资料）

## 访问与导出
生产数据库只读权限有效期为 7 天，须经数据负责人和直属经理共同审批。
客户手机号展示时仅保留前 3 位和后 4 位，中间位以星号替换。
单次导出超过 10,000 行客户记录，需要安全负责人审批，并登记用途和销毁日期。
外包人员不得下载原始客户数据，只能在隔离环境使用脱敏数据。

## 生命周期
访问审计日志保留 180 天，只有安全审计组拥有删除权限。
离职账号应在离职生效后 1 小时内停用，相关 API 密钥必须同步吊销。
测试数据每 90 天清理一次；涉及审计冻结的数据应暂停清理直至冻结解除。
敏感数据传输必须使用 TLS 1.2 或以上版本，静态存储使用 AES-256 加密。
